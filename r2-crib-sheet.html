The R2 Crib Sheet

The autonomous network ops assistant — the figure, the formulas, and every number worth saying out loud. Read in ten minutes; redraw the figure in two. Mock-interview fixes are baked in.

Say first — the framing sentence

“An ops assistant isn’t one big brain — it’s an agent inside a closed loop: awareness → analysis → decision → execution, with feedback. The LLM lives at the slow, human-facing altitude; sub-second control stays algorithmic. And the center of gravity is the safety envelope between the agent and the network.”

The figure — memorize & redraw

The 40-minute script

  1. Clarify (5) — the money question: advise or act? Then volumes, users, latency, data quality, residency.
  2. Skeleton (10) — draw the figure, narrate left→right, then the envelope.
  3. Deep dive (15) — follow their pick: retrieval, safety, eval, or serving.
  4. Eval & rollout (5) — shadow → suggest → gated execute. Say it unprompted.
  5. The trace (5) — one 3am incident, end to end, plus the low-confidence branch.

Numbers to say out loud

Workload anchor (tier-1 NOC)

  • ~500k alarms/day → ~40k events → ~8k incidents → ~3k human tickets
  • ~120 engineers · ~20 min triage · ~2 h priority MTTR
  • The LLM sees the compressed stream only — correlation/dedup stays algorithmic

Eval gates (the answer I owed the mock)

  • Golden set: ~200 historical incidents with known root cause
  • RCA top-3 accuracy ≥ 80% · citation faithfulness ≈ 100%
  • Engineer acceptance ≥ 60% · kill criterion: < 40% after one quarter → stop, re-scope
  • Auto-exec gate per MOP×scope: 6-week shadow, zero incorrect actions

Serving (volunteer this — home turf)

  • Residency → self-host open-weight in the operator’s VPC; vLLM + prefix caching (shared system prompt)
  • 70B weights: 140 / 70 / ~37 GB at FP16 / FP8 / 4-bit; or MoE gpt-oss-120b ~62 GB on one H100
  • H100 3.35 TB/s → 70B FP8 on TP2 ≈ ~48 tok/s/stream; copilot SLO: TTFT < 1–2 s, 30–50 ms/token
  • Batched $0.2–0.5 / 1M tokens → an incident (~50k tok) costs < 1¢ vs 20 engineer-minutes

KV / capacity (if they drill)

  • KV/token = 2·layers·kv_heads·head_dim·bytes → 70B GQA ≈ 0.32 MB
  • Concurrency = free HBM ÷ (KV/tok × context); Little’s law: slots = rate × latency
  • Decode is bandwidth-bound; TP aggregates bandwidth (2 GPUs ≈ 2× decode)

The five formulas

1  weights = params × bytes/weight  (FP16 2 · FP8 1 · 4-bit ~0.53)   2  KV/tok = 2 × layers × kv_heads × head_dim × bytes
3  decode tok/s ≈ HBM bandwidth ÷ bytes-read/token  (× ~60–80% real)   4  concurrency = request rate × latency  (Little’s law)
5  $/1M tok = GPU $/hr ÷ (tok/s × 3600 ÷ 1e6)  →  utilization dominates; never cost from batch-1

The autonomy ladder — per procedure × per scope

shadow (invisible)→ suggest-only (HITL)→ one-click approve→ scoped auto-exec (HOTL)

Auto-execution is never yes/no per MOP — it’s MOP × scope: one cell, this region, off change-freeze, rate-limited (max N/hr). Confidence below the gate → escalate with the evidence bundle, never act. Every execution: dry-run where a twin exists → execute → verify KQIs in a time budget → auto-rollback on failure. Actions are idempotent desired-state, so retries and rollbacks are safe.

The trace — rehearse until fluid

  1. Transport link degrades → alarm fan-out across RAN + Core; correlation compresses the storm.
  2. Agent queries topology + KPIs + last night’s CRs (tools); retrieves the matching past incident + MOP (cited).
  3. “Root: fiber degradation on link X, confidence 0.87. 50 site outages converge on one segment — chain attached. Impact: 3 enterprise slices at SLA risk. Proposed: reroute via Y, tier 2.”
  4. Tier 2 → one-click approval → execute via intent API → verify KQIs recover → post the summary to the ticket.
  5. Counterfactual: at confidence 0.5 it escalates with the evidence bundle instead of acting — safe degradation is part of the design.

The three sentences that close gaps

1 — “Anything that changes faster than my refresh cycle gets queried live, not embedded — topology, KPIs, and CR status are tools; runbooks and past tickets are RAG.”
2 — “Auto-execution is granted per-procedure and per-scope, and the gate is zero incorrect actions in a six-week shadow window plus RCA top-3 above 80%.”
3 — “Let me walk you through one incident end to end” — then the trace, including the low-confidence branch.
